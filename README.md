### Hands-on AI help for local businesses

I'm Tony. I sit with small-business teams for a day, find where the hours go, and fix the small things first, using the tools they already have. Every fix is something their staff can run without me, and nothing goes out in the owner's name without their OK.

**Tools I use with owners**

- [intake-forms](https://github.com/txmyer-dev/intake-forms): a branded, fillable new-patient packet for a small practice, generated from one file
- [website-legal-kit](https://github.com/txmyer-dev/website-legal-kit): plain-language site policies plus a review packet the owner's lawyer signs
- [call-to-sms-tickets](https://github.com/txmyer-dev/call-to-sms-tickets): missed call → ticket number by text → status link (n8n + Twilio)
- [htr-convex](https://github.com/txmyer-dev/htr-convex): my Convex "All Gas" hackathon entry, built on OpenAI. An assistant that reads everything, drafts everything, and sends nothing until the owner rules
- [skool-plus](https://github.com/txmyer-dev/skool-plus): draft community replies in your own voice; you click send

Before this: warehouse operations and enterprise IT support. Now I also teach AI to working people in the WotAI community.
